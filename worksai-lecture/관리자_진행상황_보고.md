## 1. 이번에 반영한 내용

- **1·2교시 구성 변경**: 개념 슬라이드 2장(도구 개념, 프롬프트 엔지니어링)과 크레딧 절약 3장을 2교시 끝 「⑤ 개념·프롬프트」로 옮겼습니다. 이에 맞춰 1·2교시 시간 배분도 다시 조정했습니다.
- **3교시 구성 변경**: 에이전트와 워크플로우를 모두 직접 만들어 보는 구성으로 바꿨습니다.
- **아이디어 슬라이드**: 화살표 앞에서 줄을 바꿔 읽기 쉽게 정리했습니다.
- **33·34쪽**: 내용이 슬라이드 밖으로 넘치던 부분을 정리했고, 34쪽 부제는 삭제했습니다.
- **현업 적용 슬라이드**: 위쪽 카드 3개를 강조 디자인(남색 배경, 흰 글씨, 노란 제목)으로 바꿨습니다. 다만 교안 화면에서 직접 확인하지는 못해, 다음 작업 때 확인하겠습니다.

## 2. 진행 중에 멈춘 작업 — 웍스AI 「슬라이드」 기능 안내

- 웍스AI 상단 메뉴 「슬라이드」로 발표자료를 만드는 과정을 끝까지 실제로 진행해 봤습니다(설정 → 구성안 → 초안 완성, 1장).
- 메뉴 화면, 설정 화면 3장, 구성안, 초안 화면까지 캡처해 두었습니다.
- 완성된 슬라이드 캡처와 교안 반영은 아직 하지 못했습니다.
- **43쪽은 아직 이전 내용(「온팟 슬라이드로 1장 만들기 / slide.onpod.ai/app」)으로 남아 있습니다.** 첨부본에서는 이 페이지를 참고하지 말아 주세요. 수업 전에 반드시 고치겠습니다.

## 3. 남은 작업 (한도가 풀리는 대로 이어서 진행)

1. 완성 슬라이드를 캡처하고, 43쪽을 「웍스AI 메뉴 → 슬라이드 → 새 슬라이드 설정 → 구성안 만들기 → 초안」 순서의 단계별 캡처 안내로 다시 만들기
2. 마지막 장 제목 아래에 「1교시 → 2교시 → 3교시 → 4교시」로 이어지는 전체 흐름 도식 넣기
3. 전체 슬라이드에서 요소 겹침·넘침 다시 점검하기

## 4. 여쭤보고 싶은 사항

**① 교육생 호칭**
교안과 강의에서 교육생분들을 어떻게 부르면 좋을지 여쭙습니다.
(예: "교육생 여러분", "선생님", "OOO님" 등) 기관에서 쓰는 호칭이 있으면 그대로 맞추겠습니다.

**② 웍스AI 크레딧 한도 조정 가능 여부**
교안 제작과 실습 시연 중에 웍스AI 크레딧 한도에 도달했습니다.
강의 준비와 당일 시연을 위해 **강사 계정의 한도를 늘려주실 수 있는지** 여쭙습니다.
어렵다면 한도가 언제 초기화되는지, 수업 당일 교육생분들 계정의 크레딧은 실습하기에 충분한지도 함께 알려주시면 실습 분량을 조정하겠습니다.
